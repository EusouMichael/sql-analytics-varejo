# Banco de dados

O projeto utiliza uma base SQLite chamada `banco_de_dados_vendas.db`.

A base original possui aproximadamente 6,5 MB. Nesta etapa, os scripts SQL e os resultados derivados foram publicados no repositório, mas o arquivo binário SQLite não foi enviado pela integração do GitHub disponível nesta conversa.

Para executar as consultas localmente, coloque o arquivo `banco_de_dados_vendas.db` nesta pasta e abra-o com SQLite/DB Browser for SQLite.

O pacote completo entregue junto ao projeto contém o banco original.
