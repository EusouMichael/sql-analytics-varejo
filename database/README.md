# Banco de dados

O projeto utiliza a base SQLite `banco_de_dados_vendas.db`, armazenada nesta mesma pasta.

## Como utilizar

1. Baixe ou clone o repositório.
2. Abra `banco_de_dados_vendas.db` no SQLite ou no DB Browser for SQLite.
3. Execute os scripts disponíveis em `sql/`.
4. Compare os resultados com os arquivos publicados em `resultados/`.

O banco possui aproximadamente 6,7 MB e faz parte do repositório para permitir a reprodução local das consultas.

> Os resultados e as consultas foram organizados para estudo e portfólio. As métricas devem ser interpretadas considerando as limitações documentadas no README principal.
